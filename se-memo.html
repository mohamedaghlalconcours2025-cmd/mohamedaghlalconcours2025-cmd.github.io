SE, recto : l'exercice (16 pts)

Mémo de révision, 2AP

Pour chaque algorithme, dans l'ordre

  • Gantt → Ti → T̄ → Wi → W̄ → débit → rendement du CPU

Qui passe ? une ligne par algorithme

  • FCFS : le premier arrivé. Jamais coupé.
  • SJF : la plus courte durée. Jamais coupé.
  • SRTF : le plus court temps restant. Coupe.
  • Priorité non préemptive : la plus haute priorité (1 ou Critique). Jamais coupé.
  • Priorité préemptive : la plus haute ; coupe dès qu'un plus prioritaire arrive.
  • RR (quantum q) : la file ; q secondes au plus, puis retour en fin de file.

Frontière

  • On coupe = préemptif : SRTF, priorité préemptive, RR.
  • Tout le reste : non préemptif.
  • Égalité : le premier arrivé passe ; un égal ne coupe jamais.

Formules

  • Ti = Fi − Ai (fin − arrivée)
  • Wi = Ti − Ci (rotation − durée)
  • T̄ et W̄ : la moyenne (÷ n), pas la somme
  • débit = terminés avant Tobs ÷ Tobs
  • rendement du CPU = temps où il travaille ÷ Tobs
  • CPU ralenti : durée ÷ nouvelle perf. (2 s à 82 % : 2 ÷ 0,82)

7 pièges

  • Débit : tracer un trait à Tobs et ne compter que les fins avant le trait.
  • Préemptif : à chaque date d'arrivée, se demander si le nouveau passe devant.
  • RR : l'ordre d'entrée dans la file, pas d'arrivée en RAM ; le processus coupé repart au bout.
  • SJF ne coupe pas : si on coupe, c'est du SRTF.
  • Un processus qui finit avant la fin de son quantum : le suivant démarre aussitôt.
  • Vérif : les morceaux de chaque processus = sa durée ; la fin du Gantt = la somme des durées (si le CPU n'est jamais vide).
  • CPU ralenti : on divise, on ne multiplie jamais.

Le modèle 2025 pour se caler

  • 5 processus, Tobs = 20 s, somme des durées = 24 s : pas tous finis à 20 s.
  • FCFS : T̄ = 14,2 ; W̄ = 9,4 ; débit = 3/20 = 0,15 · rendement du CPU = 20/20 = 100 %.

SE, verso : le cours (4 pts)

Une phrase du cours + un exemple

Bases diapos 1 à 43

  • SE : logiciel fondamental (ensemble de programmes) qui gère les ressources matérielles et logicielles. 3 rôles GIS : Gérer sans conflit, Interface utilisateur-matériel, Sécurité.
  • BIOS : programme en ROM sur la carte mère, le 1er exécuté : POST → périphériques → chargeur → SE.
  • UAL (unité de traitement) calcule : + − ET OU. Unité de commande : lit, décode, fait exécuter (fetch-decode-execute).
  • Registre : petite mémoire dans le CPU. Cache : petite mémoire rapide près du CPU. Horloge : synchronise (MHz).
  • Bus quoi-où-comment : données (↔), adresse (→, 2n), commande (signaux).
  • Hyperviseur : SE dans une machine virtuelle. Type 1 sur le métal nu (Hyper-V) ; type 2 invité dans un SE (VMware Workstation).

4 modes choisis par le SE, tout seul

  • Séquentiel direct : un humain entre chaque programme ; indirect : lots, automatique.
  • Multiprogrammation classique : on change quand le programme attend une E/S ; étendue : + pagination, segmentation.
  • Temps partagé : un quantum chacun, on change même s'il n'est pas bloqué.
  • Temps réel : finir avant la deadline (avion, FreeRTOS, QNX).

4 architectures

  • Monolithique : un seul bloc, tout en mode noyau. UNIX, MS-DOS.
  • En couches : chaque couche n'utilise que celle du dessous. THE.
  • Micro-noyau : le minimum (ordonnancement, mémoire, IPC), le reste en espace utilisateur. Minix, QNX.
  • Hybride : rapide comme le monolithique, fiable comme le micro-noyau. Windows, macOS.

Noyau, E/S, interruptions

  • Noyau : cœur du SE. P-M-P-F : processus, mémoire, périphériques, fichiers.
  • Pilote : programme qui fait parler le SE et un périphérique (clavier).
  • E/S : le CPU demande (programmées) → est prévenu (interruptions) → délègue (DMA). CPU de moins en moins sollicité, de plus en plus rapide.
  • DMA : composant matériel. Le CPU prépare → le DMA copie seul → interruption de fin → le CPU vérifie.
  • Interruption : signal, attention immédiate. Types : matérielle, logicielle, horloge.
  • Niveaux panne > horloge > E/S > logicielle (le timer passe avant le clavier).
  • Étapes, le marque-page : détection → sauvegarde du contexte → ISR → restauration → reprise.
  • PIC : le standardiste (priorité, masquage). ISR : la routine qui traite.
  • 5 fonctions réagir, communiquer, trier, sauvegarder, ordonnancer.

Processus

  • Processus : programme en cours d'exécution, avec ses ressources. Programme passif, processus actif.
  • Ordonnanceur : choisit qui a le CPU et quand ; il utilise un algorithme (RR).
  • Cycle, le guichet : création → prêt (attend le CPU) → exécution → attente (attend une ressource) → fin.
  • PCB : sa carte d'identité. PID, état, compteur de programme, mémoire, ressources, priorité, temps CPU.
  • Files : prêts et bloqués. Table : tous les PCB, rangés par PID.
